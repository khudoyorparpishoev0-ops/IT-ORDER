# Спецификация дизайна платформы "Табель расходов"

## 1. Обзор проекта

**Название:** Платформа управления заявками на расходы сотрудников  
**Целевая аудитория:** Менеджеры, супервайзеры, руководители отделов  
**Назначение:** Централизованное управление, утверждение и отслеживание заявок на расходы сотрудников

---

## 2. Архитектура информации

### Основные разделы платформы (8 секций)

1. **Панель управления** (Dashboard)
   - Статистика по заявкам (всего, на утверждении, одобрено, оплачено)
   - Бюджет команды
   - Последние заявки на утверждение
   - Ключевые метрики

2. **Заявки** (Requests)
   - Полный список заявок сотрудников
   - Фильтрация по статусу, периоду, сотруднику
   - Просмотр деталей заявки
   - Поиск

3. **Согласование** (Approvals)
   - Заявки на утверждение
   - Форма утверждения/отклонения
   - Комментарии и история изменений
   - Быстрое действие (одобрить/отклонить)

4. **Отчёты** (Reports)
   - Аналитика расходов
   - Графики по проектам
   - Графики по сотрудникам
   - Экспорт в Excel/PDF
   - Сравнение с бюджетом

5. **Команда** (Team)
   - Список сотрудников
   - Назначение лимитов
   - История заявок по сотруднику
   - Управление доступом

6. **Финансы** (Finance)
   - Управление бюджетом
   - Утверждение платежей
   - Возмещение расходов
   - Банковские реквизиты

7. **Параметры** (Settings)
   - Профиль менеджера
   - Правила и политики
   - Интеграции
   - Уведомления
   - Темы оформления

8. **Справка** (Help)
   - FAQ и вопросы
   - Документация
   - Контакты поддержки
   - Гайды и видеоуроки

---

## 3. Цветовая схема

### Палитра цветов

**Основной цвет (Primary): Тёмно-зелёный**
```
HEX: #2D5F3F
RGB: 45, 95, 63
Использование: Логотип, иконки, акценты, основной брендинг
```

**Вторичный цвет (Secondary): Серый**
```
HEX: #6B7280
RGB: 107, 114, 128
Использование: Текст, границы, фон карточек
```

**Статусы и семантические цвета**

| Статус | Цвет | HEX | Значение |
|--------|------|-----|----------|
| На утверждении | Янтарный | #D4A574 | Требует действия |
| Одобрена | Голубой | #4A90E2 | Успешно утверждено |
| Оплачена | Зелёный | #50C878 | Завершено |
| Отклонена | Красный | #E74C3C | Отказано |
| Черновик | Серый | #95989A | Не отправлено |

### Модель тем

Поддерживаются **две темы**:
- **Light Mode (светлая)** — основная тема для работы
- **Dark Mode (тёмная)** — для вечерней работы

Переключение темы доступно в параметрах профиля менеджера.

## 5. Компоненты интерфейса

### Навигация

**Тип:** Топ-навигация (горизонтальное меню в шапке)

**Структура:**
```
[Логотип] [Панель] [Заявки] [Согласование] [Отчёты] [Параметры] | [Профиль]
```

**Поведение:**
- Активный элемент выделяется цветом основного бренда (#2D5F3F)
- Наведение — смена фона на серый (#F3F4F6)
- Высота шапки: 64px

### Карточки

**Стиль:**
- Фон: Белый / Светло-серый (в зависимости от темы)
- Граница: 0.5px solid #E5E7EB (светлая тема)
- Скругление углов: 12px
- Padding: 1.5rem
- Тень: легкая (для выделения)

**Типы карточек:**
1. **Stat Card** — метрики (высота: 140px)
2. **Claim Card** — информация о заявке
3. **Action Card** — с кнопками действий

### Кнопки

**Основные стили:**

| Тип | Фон | Текст | Использование |
|-----|-----|-------|-----------------|
| Primary | #2D5F3F | Белый | Основные действия (одобрить, отправить) |
| Secondary | Прозрачный | #2D5F3F | Вторичные действия |
| Danger | #E74C3C | Белый | Удаление, отклонение |
| Ghost | Прозрачный | Серый | Неприоритетные действия |

**Размеры:**
- Large: 44px высота, 16px padding горизонтальный
- Medium: 36px высота, 12px padding горизонтальный
- Small: 28px высота, 8px padding горизонтальный

**Hover-эффекты:**
- Opacity: 90% или более светлый оттенок
- Transition: 0.2s

### Входные поля

**Стиль:**
- Фон: Белый / Светло-серый
- Граница: 0.5px solid #D1D5DB
- Высота: 36px
- Padding: 8px 12px
- Border-radius: 8px
- Шрифт: 14px

**Focus:**
- Граница: 2px solid #2D5F3F
- Shadow: 0 0 0 3px rgba(45, 95, 63, 0.1)

### Таблицы

**Структура:**
- Header row: Bold текст, фон #F3F4F6
- Data rows: 44px высота
- Разделители: 0.5px solid #E5E7EB
- Hover: Фон #F9FAFB

**Колонки:**
```
| Сотрудник | Проект | Сумма | Статус | Действие |
|-----------|--------|-------|--------|----------|
| 1.5fr     | 1.2fr  | 0.8fr | 0.8fr  | 0.6fr    |
```

### Статус-бейджи

**Оформление:**
- Padding: 4px 12px
- Border-radius: 6px
- Font-size: 12px
- Font-weight: 500

**Варианты:**
```
[На утверждении] — #D4A574 фон, белый текст
[Одобрена] — #4A90E2 фон, белый текст
[Оплачена] — #50C878 фон, белый текст
[Отклонена] — #E74C3C фон, белый текст
```

### Иконки

**Стандартная библиотека:** Tabler Icons (outline)

**Размеры:**
- В заголовках: 20px
- В кнопках: 16px
- В таблицах: 18px
- Декоративные: 24px

**Цвета:**
- Основной цвет: #2D5F3F
- Вторичный: #6B7280
- Успех: #50C878
- Ошибка: #E74C3C

## 6. Макет и сетка

### Общие принципы

- **Max-width:** 1200px для контента
- **Padding:** 1.5rem по бокам на мобильных, 2rem на десктопе
- **Grid:** 12 колонок
- **Gap:** 1.5rem между элементами

### Адаптивность

| Breakpoint | Ширина | Grid |
|------------|--------|------|
| Mobile | < 640px | 1 колонка |
| Tablet | 640px - 1024px | 2 колонки |
| Desktop | > 1024px | 4 колонки |

## 7. Макеты основных экранов

### 7.1 Панель управления (Dashboard)

**Структура:**
```
[Навигация]
[Заголовок] "Панель управления"
[Строка метрик — 4 stat card]
  - Всего заявок
  - Одобрено
  - На утверждении
  - Бюджет на месяц

[Таблица "Последние заявки"]
  Столбцы: Сотрудник | Сумма | Проект | Статус | Действие

[Секция "Цветовая схема и компоненты"]
```

**Компоненты:**
- Header: H1 заголовок
- Stats Grid: 4 карточки в сетке
- Table: с фильтрацией
- Action buttons: Одобрить, Отклонить, Просмотреть

### 7.2 Заявки (Requests)

**Структура:**
```
[Навигация]
[Фильтры: Статус | Период | Сотрудник | Проект]
[Таблица со всеми заявками]
  - Сортировка по колонкам
  - Пагинация
  - Выделение строк

[Модал для просмотра деталей]
  - Информация о заявке
  - Список расходов
  - История изменений
```

### 7.3 Согласование (Approvals)

**Структура:**
```
[Навигация]
[Фильтр: На утверждении | Утверждены | Отклонены]

[Карточка заявки для утверждения]
  - Данные сотрудника
  - Таблица расходов
  - Итоговая сумма
  
[Форма решения]
  [Действие: Одобрить | Отклонить]
  [Комментарий: Textarea]
  [Кнопки: Отправить | Отмена]

[История предыдущих действий]
```

## 9. Принципы взаимодействия

### Обратная связь пользователю

**Toast-уведомления (появляются в верхнем правом углу):**
- ✓ Успех: "Заявка одобрена" (зелёный)
- ⚠ Предупреждение: "Проверьте сумму" (янтарный)
- ✗ Ошибка: "Ошибка сервера" (красный)
- ℹ Информация: "Загрузка данных..." (синий)

**Модальные диалоги:**
- Подтверждение удаления
- Форма новой заявки
- Форма комментария
- Экспорт отчёта

### Микровзаимодействия

1. **Hover на кнопках** — изменение цвета/opacity
2. **Click на строке таблицы** — выделение + возможность редактирования
3. **Загрузка** — spinner в центре или skeleton-loading
4. **Empty state** — иконка + текст "Нет заявок"

## 10. Доступность (Accessibility)

### Требования WCAG 2.1 уровень AA

1. **Контраст текста** — минимум 4.5:1
2. **Размер шрифта** — минимум 14px для основного текста
3. **Кнопки** — минимум 44x44px (сенсорный размер)
4. **Навигация с клавиатуры** — все элементы должны быть доступны
5. **Alt-текст для иконок**
6. **ARIA-метки** для скрин-ридеров
