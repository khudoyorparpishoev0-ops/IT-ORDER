# Промпт для Claude Design - Платформа "Табель расходов"

## Основная информация

Ты дизайнер интерфейсов. Создай дизайн-систему и макеты для корпоративной платформы управления заявками на расходы.

## Контекст проекта

**Название:** Платформа управления заявками на расходы  
**Пользователи:** Менеджеры, супервайзеры, руководители отделов  
**Назначение:** Централизованное утверждение и отслеживание расходов сотрудников  
**Размер:** 8 основных разделов платформы

## Спецификация стиля

### Цветовая палитра (Обязательно!)

**Основной цвет:** Тёмно-зелёный #2D5F3F  
**Вторичный цвет:** Серый #6B7280  

**Статусы:**
- На утверждении: #D4A574 (янтарный)
- Одобрена: #4A90E2 (голубой)
- Оплачена: #50C878 (зелёный)
- Отклонена: #E74C3C (красный)

### Типография

**Шрифт:** Anthropic Sans (или аналогичный sans-serif)

**Размеры:**
- H1: 28px / 500 вес
- H2: 20px / 500 вес
- H3: 16px / 500 вес
- Body: 14px / 400 вес
- Small: 13px / 400 вес

### Тема оформления

**Поддерживаются две темы:**
- Light Mode (основная)
- Dark Mode (для вечерней работы)

Все цвета должны работать в обеих темах.

### Навигация

**Тип:** Только топ-навигация (горизонтальное меню в шапке)  
**Высота:** 64px  
**Структура меню:**
1. Панель (Dashboard)
2. Заявки (Requests)
3. Согласование (Approvals)
4. Отчёты (Reports)
5. Команда (Team)
6. Финансы (Finance)
7. Параметры (Settings)
8. Справка (Help)

## Требуемые макеты

### 1. Панель управления (Dashboard)
Создай экран с:
- Header: "Панель управления"
- 4 stat card в сетке:
  - Всего заявок (24)
  - Одобрено (₽18 500)
  - На утверждении (₽3 200)
  - Бюджет на месяц (₽156 000)
- Таблица "Последние заявки" с колонками: Сотрудник | Проект | Сумма | Статус | Действие
- Статус-бейджи для каждой строки

### 2. Страница Согласования (Approvals)
Создай экран с:
- Карточка заявки для утверждения:
  - Данные сотрудника (ФИ, должность, контакты)
  - Таблица расходов (описание, кол-во, цена, сумма)
  - Итоговая сумма
- Форма решения:
  - Радио-кнопки: Одобрить | Отклонить
  - Textarea для комментариев
  - Кнопки: Отправить | Отмена
- История изменений внизу

### 3. Система компонентов
Покажи примеры:
- Карточек (card)
- Кнопок (primary, secondary, danger)
- Входных полей (input, textarea)
- Таблиц
- Статус-бейджей
- Иконок (используй Tabler Icons)

### 4. Цветовая схема
Создай палитру, которая показывает:
- Основные цвета
- Статусы
- Семантические цвета
- Варианты для Light/Dark mode

## Принципы дизайна

1. **Минимализм** — только необходимые элементы
2. **Иерархия** — заявки на утверждении выделены ярче всего
3. **Консистентность** — одинаковые размеры, отступы, цвета везде
4. **Доступность** — контраст ≥ 4.5:1, размер кнопок ≥ 44px
5. **Адаптивность** — работает на мобильных, планшетах, десктопах

## Детали стиля

### Скругление углов
- Карточки: 12px
- Кнопки: 8px
- Входные поля: 8px

### Отступы (Padding)
- Внутри карточек: 1.5rem
- Между элементами: 1rem, 1.5rem, 2rem

### Тени
- Легкие (subtle) для карточек
- Вообще не использовать на мобильных

### Бордеры
- Базовая граница: 0.5px solid (используй цвет из палитры)
- На focus элементах: 2px solid основной цвет

## Пример работы менеджера (User Flow)

1. Менеджер логинится → видит Панель управления
2. Видит статистику: 5 заявок на утверждении
3. Кликает на "Согласование" → список заявок на утверждении
4. Выбирает заявку → видит детали с расходами
5. Одобряет заявку → видит уведомление "Заявка одобрена"
6. Переходит в "Отчёты" → видит графики расходов
7. Экспортирует отчёт в Excel
