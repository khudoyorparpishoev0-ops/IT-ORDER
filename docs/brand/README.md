# Логотип IT-HONA — исходные файлы

`Logogreen.svg`, `Logowhite.svg`, `Logoblack.svg` — официальные файлы из
бренд-пакета (экспорт CorelDRAW 2021). Здесь они лежат как источник: панель
их не грузит.

**Почему панель их не использует напрямую.** Написание имени в этих файлах —
не контуры, а текст, набранный шрифтом Uni Neue Light, который приложен как
SVG-шрифт (`<font>` / `<glyph>` внутри `<defs>`). SVG-шрифты не поддерживает
ни один современный браузер: Chrome убрал их в 38-й версии, Firefox и Safari
никогда не поддерживали. В браузере такой файл покажет имя случайным
системным шрифтом.

Поэтому буквы разложены в контуры в `frontend/src/components/Logo.tsx`: те же
глифы из того же файла, те же ширины и тот же горизонтальный масштаб 1,55,
что задал дизайнер. Знак взят как есть — он и в исходнике полигон.

Если из бренд-пакета придёт версия, где имя уже переведено в кривые
(в Corel: «Преобразовать в кривые» перед экспортом), её можно вставить в
компонент напрямую, заменив содержимое `Wordmark`. Композиции и отступы при
этом не трогать.
